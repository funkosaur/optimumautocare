# Optimum Auto Care

Single-page website for Optimum Auto Care, a mobile vehicle repair company based in Brighton, East Sussex.

## Stack

- PHP 8.3
- Vanilla CSS (mobile-first, dark theme)
- Vanilla JS (no frameworks, no dependencies)
- Hosted on Hostinger shared hosting

## Structure

```
public_html/
├── index.php          — Single page with all sections
├── send-mail.php      — Contact form handler (PHP mail())
├── css/
│   └── style.css      — All styles
├── js/
│   └── main.js        — Menu toggle, smooth scroll, form validation
└── images/
```

## Local Development

```bash
cd public_html
php -S localhost:9001
```
